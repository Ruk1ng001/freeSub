## 🔤 节点名怎么读

所有客户端使用同一套名称，例如：

```
A🟢🇯🇵res[🤖🎬📺]_dokng.com_a1b2c3d4
```

依次为质量等级、风险颜色、出口地区旗帜、IP 类型、可用服务图标、赞助标记和
连接短 ID。ID 通常取完整连接摘要前 8 位，碰撞时延长；节点身份不依赖名称。

### 🎚️ 质量、风险颜色与 IP 类型

| 颜色 | 等级 | 本次规则判定 |
|:---:|:---:|---|
| 🟢 | A+ / A | 公共 GeoIP 标志与 ASN 规则判定为较低风险 |
| 🟡 | B | 一般风险 |
| 🟠 | C | 托管、机房等偏高风险特征 |
| 🔴 | D | 明确代理等高风险特征 |
| ⚪ | U | 证据不足，保持未知 |

类型简写为 `res` 住宅、`mob` 移动、`hos` 托管、`bus` 商业、`cdn` 内容分发、
`ukn` 未知。类型与质量来自公共 GeoIP 观测的规则判定，不是付费风险情报。
地区旗帜来自本次真实出口查询，不能确认时显示 🏳️，不会从上游名称猜测。

## 🧠 地区、场景分组与排序

Clash 恢复地区、AI/媒体、自动测速、直连/拦截及入口组合分组与原规则。
地区和服务组的直接节点只使用本批对应实测事实，空地区组按模板省略。
旧模板的备用组引用仍保留，备用路由不表示节点取得了该地区或服务标签。

候选通过真实连通检测和完整下载测速，先按本轮速度降序、延迟升序排序。
场景组再按模板条件选择成员；客户端自动测速和备用切换按各组配置运行。
当前没有把多轮可用率、未知抖动或未测项目补成综合分。

Sing-box 保留基础 General 选择组和路由，V2Ray 为分享链接。各格式只保留能完整
表达全部连接参数的节点，因此数量可以不同。测速、地区/服务观测、生成和发布
各有真实时间，新的发布时间不会刷新旧测量事实。
