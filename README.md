### 🎚️ 质量等级与风险图标

质量等级综合 IP 类型（住宅 / 机房 / CDN）与风险评级得出，风险图标是它的颜色化表示：

| 图标 | 等级 | 含义 |
|:---:|:---:|------|
| 🟢 | `A+` / `A` | 干净 IP，多为住宅或低风险，AI 与流媒体成功率最高 |
| 🟡 | `B` | 一般，日常够用，部分风控站点可能要验证 |
| 🟠 | `C` | 偏高风险，机房 IP 居多，AI 服务容易被拒 |
| 🔴 | `D` | 高风险，已被广泛标记，仅建议应急 |
| ⚪ | `U` | 未知，GeoIP 数据缺失 |

> 挑节点看不懂细节时，认颜色就够：**优先 🟢，其次 🟡**。

## 🧠 智能分组与节点评分

本订阅内置**综合评分**与**场景化分组**，开箱即用、自动择优 —— 多数情况下你只需选中分组，无需手动逐个测速。

### 综合评分（CompositeScore）

每个节点都经过多维实时测试，融合为一个综合评分（0-100）：

| 维度 | 说明 |
|:---:|------|
| 🌐 延迟 / 抖动 | 越低越稳定、响应越快 |
| 🚀 下载速度 | 越高网速越快 |
| ✅ 可用率 | 最近多次检测的历史成功率，越高越可靠耐用 |
| 🏠 IP 质量 | 住宅 / 机房、风险等级等 |

代理组默认按综合评分自动选出当前最优节点，并持续依据可用率淘汰长期不稳定的节点。

### 场景化分组

按使用场景挑选最合适的出口，选中对应分组即可，组内会基于「解锁能力 + 综合评分」自动选优：

| 分组 | 适用场景 |
|:---:|------|
| 🧠 AI | ChatGPT / Claude / Gemini 等 AI 服务 |
| 🎞️ 流媒体 | Netflix / YouTube / Disney+ / Spotify 等 |
| 🌐 通用 | 日常上网，自动选综合评分最优的节点 |

> 💡 提示：优先选中场景分组（或地区分组），让客户端自动选优；遇到卡顿时切换分组即可。
